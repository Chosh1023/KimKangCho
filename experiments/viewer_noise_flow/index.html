Noise Flow 궤적 비교

초기 경로 없이 가우시안 노이즈에서 출발하는 Noise Flow(후보 64개, 상위 3개 구조, Euler 16 step)를 Hybrid A*(HA*) 단독, HA* + IPOPT, 기준 OCP 해(GT)와 같은 주차 장면에서 비교합니다. J = T + 0.5·∫(a² + v²·δ̇²)dt, 목표 허용 오차 0.1 m / 5°.

평가 장면 500개 요약

방법성공J 중앙값GT 대비 J 중앙값GT 대비 J 평균계산 시간 중앙값계산 시간 평균
요약을 불러오는 중입니다.

J와 GT 대비 J는 네 방법이 모두 성공한 장면 기준, 성공률과 계산 시간은 500개 장면 전체(실패 포함) 기준입니다.

장면

GT 대비 Noise Flow J 순. 1 미만은 Noise Flow가 GT보다 낮은 J를 낸 장면입니다.

경로

BEV 좌표, 위쪽이 자차 전방. 회색은 장애물, 초록 사각형은 목표 주차칸, 원은 기어 전환 지점입니다. 실선 윤곽은 시작 자세, 점선 윤곽은 목표 자세의 차량입니다.

이 장면JGT 대비주행 시간기어 전환계산 시간

계산 시간: Noise Flow는 입력 인코딩부터 최종 경로 선택까지(후보 64개 생성과 검증 포함), HA* + IPOPT는 HA* 탐색 시간과 IPOPT 시간의 합입니다. GT는 계산 시간이 기록되어 있지 않습니다.

속도 — 시간

후진도 속도 크기로 표시합니다. 0으로 떨어지는 지점은 기어 전환 정지입니다.
